# Peerphonic Helm chart

The chart installs Peerphonic, its optional web dashboard, PostgreSQL, persistent
storage, and an optional slskd sidecar.

See the repository's [Kubernetes installation guide](../../../docs/installation/kubernetes.md)
for a generic installation, storage choices, ingress, P2P networking, backups,
and upgrades. All chart options and supported Secret key mappings are listed in
[`values.yaml`](values.yaml).
